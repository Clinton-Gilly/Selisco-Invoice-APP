Publishing Future Updates (Quick Reference)
Whenever you build a new update (e.g. v1.0.1):

Bump the version in mobile/pubspec.yaml (e.g., version: 1.0.1+2) and currentVersion = '1.0.1' in mobile/lib/core/services/app_update_service.dart.
Build the release APK:
powershell


cd mobile; flutter build apk --release; cd ..
Commit and push:
powershell


git add . ; git commit -m "release: v1.0.1 - [describe changes]" ; git push origin main
Create the new release:
powershell


gh release create v1.0.1 mobile/build/app/outputs/flutter-apk/app-release.apk --title "Selisco Mobile v1.0.1" --notes "Added [feature notes]"
